# Moyo Private Clinic — portfolio concept

A responsive multi-page HTML, CSS and JavaScript website concept for a modern private clinic in Lusaka, Zambia.

## Pages
- `index.html` — editorial homepage and care overview
- `services.html` — care pathways and service descriptions
- `about.html` — brand story and values
- `team.html` — care-team standards (no invented clinician credentials)
- `contact.html` — visit information and a front-end demo enquiry form

## Structure
- `assets/css/global.css` — shared design system, navigation, buttons, footer, responsive foundations
- `assets/css/home.css` — homepage-only styling
- `assets/css/services.css` — services page styling
- `assets/css/about.css` — story page styling
- `assets/css/team.css` — care-team page styling
- `assets/css/contact.css` — contact and form styling
- `assets/js/main.js` — mobile navigation and demo form validation

## Run locally
Open `index.html` in a browser, or serve the repository root with any static web server.

## Before a real launch
This is a portfolio design, not a verified operating clinic. Replace the concept brand, address, hours, services, images and contact details with verified information. The enquiry form intentionally does not send or store information. Connect it to a secure, privacy-aware backend before using it for real enquiries. Confirm all services and clinical claims with appropriately licensed providers. Do not use the website for emergency advice.

The hero uses a healthcare-specific photograph from Unsplash; other page artwork is created with CSS rather than generic stock imagery.
